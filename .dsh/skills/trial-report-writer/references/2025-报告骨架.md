### 7.4 品系晋级：必须写清两件事

**① 晋级方法**（表 7-3「晋级筛选规则（管线口径）」）——管线 `analyze_screening()` 的 5 条规则：

1. 阶段名称含「分离」的走分离选单株通道，不进晋级名单；⚠️ 管线的「阶段名称」经列名映射后是 `stageid`（材料编号），判的是**编号里有没有「分离」二字**，**不是看性状**；性状分离记在质量性状列的 `99-分离` 取值里，**不参与晋级判定**，晋级材料表末列要另加「性状分离」列（无则写「无」）
2. **两套位次 AND**：「较临近对照位次」与「较平均对照位次」**同时** ≤ 阈值（默认 60）；
3. 排除 `9-严重倒`、`7-重倒`；
4. 晋级用 **≤**、分离选单株用 **<**；
5. 对照位没有位次（NA），既不晋级、也被计入淘汰名单（原因记「未知」）。

位次是**材料层**口径（不含对照位），且**并列取相同名次**（最小排名）——所以最大位次可能小于材料数，
阈值边界上的并列材料会一并入选，**实际入选数可能多于阈值本身**。

**①′ 两张晋级表（表 7-4 / 表 7-5）的末列「田间评价」**——人工田间评价与管线数字
**分列两栏，不混算**：表末列取自附录 A.4「材料田间评价表」（按小区 ID `stageid` 关联），
没田间文字的写「—」。这样读者在正文就能看出晋级材料在田里的实际表现，
不必翻附录。**注意**：田间评价文字是人工结论，不能反过来改管线出的亩产/位次。

**② 晋级位次阈值的调整方法**——三处入口，同一套口径：

| 入口 | 位置 | 参数 |
|---|---|---|
| 应用内 | 产量试验记录页点「分析」→ 分析弹窗 → **「品种筛选」标签页** → 顶部「调整筛选参数（实时更新，无需重新分析）」卡片 | 滑块「晋级位次阈值」「分离选单株位次阈值」（1–100、步长 1、默认 60）+「排除倒伏等级」多选框（默认勾 `9-严重倒`、`7-重倒`） |
| 函数 | `shared/analysis/analysis_screening.R` | `analyze_screening(rank_threshold_select=, rank_threshold_plant=, exclude_lodging=)` |
| 命令行 | `scripts/analyze_trial.R` | `--rank <晋级阈值> --plant <分离阈值> --lodging 9,7`（例：`--rank 60 --plant 60 --lodging 9,7`） |

⚠️ **应用内两处不跟滑块走**（源码实测）：「亲本分析」标签页（表 7-7/7-8、图 7-12）
用 `rv$analysis_result` 快照；「导出」标签页打包的也是 `rv$analysis_result`，
**不是当前滑块值**——拖完滑块再导出，拿到的仍是旧阈值的表和图。
所以报告要新阈值的结果，只能命令行重跑管线。

**改阈值必须重跑管线重出数字，不许手改报告里的数。**
重出的清单：晋级名单/晋级率/晋级材料亩产与区间/淘汰名单与原因（表 7-4、表 7-5）、
晋级位次阈值敏感性（表 7-6）、亲本与组合晋级统计（表 7-7、表 7-8、图 7-12）、
筛选前后对比图与雷达图（图 7-11、图 7-13）、结论里引用的晋级数。

要说明阈值的杠杆效应就加一张敏感性表（表 7-6），**必须用管线实跑多档阈值得到**
（N-4.2 实跑 8 档：阈值 20→15 份/266.57；30→20/261.11；40→29/254.95；
50→34/252.30；60→44/248.82；70→53/245.38；80→64/242.94；100→90/236.45 kg/亩
——**阈值越大产量下限越低**），
**不许拿管线位次列自己推算晋级数**。

**③ 亲本口径的警告**：亲本/组合分析的「晋级」在管线里写死为「较平均对照位次 ≤ 60」
（`shared/analysis/analysis_parent_cross.R`），**不跟筛选阈值走**——阈值改了，
表 7-7/7-8/图 7-12 的晋级数不变。报告里要把两套口径分开说（§7.5 加 ⚠️、
附录 A.6 记一条），别让读者以为表 7-5 的 90 份和表 7-8 的晋级数是一回事。

还要写「**定阈值的三条约束**」：① 容量约束（下游阶段能装多少，但下游名单
往往来源更广，只能当粗上限）；② 质量约束（晋级群体最低亩产 vs 有效对照均值，
N-4.2 里阈值 ≤40 群体底部不低于对照、≥50 跌破）；③ 口径约束（阈值 ≠ 晋级份数，
实际晋级数约为阈值的 0.67–0.90 倍）。配一句「本报告取 X 的理由」——
规模收益 vs 群体底部低于对照的代价。

### A.4 材料田间评价表（本样板增量）

**逐材料一行**，六列：`stageid` / `name` / `亩产 (kg/亩)` / `较临近对照位次` /
`较平均对照位次` / `田间评价`，**按亩产从高到低排列**（无产量的排在表末）。

- **亩产与两套位次必须取自管线 CSV**（`数据表/yield_ranking.csv`），**不许手算**。
  位次是**材料层**口径（分母 = 有产量的材料数，不含对照）；两套基准都要给，
  因为管线筛选对两个位次列用 AND 逻辑。
- **对照位**（每 20 号一个的中黄301）本身也是基准：**有亩产、无位次**，
  混排在表里并可在 name 列标注，一眼能看出该材料相对邻近对照的位置。
- 田间评价的三类来源合并进同一格：

| 标签 | 来源 |
|---|---|
| `08-08｜` `09-01｜` `09-24｜` `10月｜` | 四轮巡田 md 笔记 |
| `库-08-30｜` `库-09-17｜` `库-备注｜` | 数据库 `TianJianBeiZhu` 田间备注（带日期的插进对应时间位） |
| `库-苗期｜` `库-花期｜` `库-成熟期｜` | 数据库三个分期评价字段 |
